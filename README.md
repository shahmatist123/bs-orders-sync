# bs-orders-sync

Мини-синхронизатор заявок: забирает `https://test.ooobs.ru/api/orders`, приводит телефоны к `+7XXXXXXXXXX`, отбрасывает невалидные, схлопывает дубли по телефону (максимальный `amount`, при равенстве — более поздний `created_at`) и отдаёт `{clients, stats}`.

- Запуск: `PORT=8000 python3 app.py`, без зависимостей (только стандартная библиотека).
- Идемпотентность: сервис без состояния, каждый запрос заново считает результат из источника детерминированно, клиенты отсортированы по телефону — повтор даёт тот же JSON.
- Секреты: в задаче их нет; адрес источника задаётся переменной `SOURCE_URL`. Ключи, если появятся, — только в переменных окружения сервера, `.env` в `.gitignore`.
